# Observed Activity Patterns — Theo

Patterns the dashboard surfaces because they recur and matter. Append to this file when a new pattern emerges across multiple weeks.

- **HRmax observed:** 198 bpm
- **LT proxy:** ~180–185 bpm

- **Location:** Ballito, KZN — warm/humid mornings (5–6 am starts)
- **Watch:** Garmin epix
- **Strava handle:** (see Strava profile)

## Known tendencies (to watch for and warn on)

1. **Easy runs creep into tempo HR.** Pre-PF, Monday "easy" runs were routinely 6:09/km at HR 158 — that's threshold, not easy. → Dashboard flags any "easy" labeled run with avg HR >160.

2. **Skips warmups before time trials.** 18 Apr TT km 1 was 6:13 cold; km 1 of 22 Mar baseline was 7:30 warmup. → Dashboard's race-day checklist always reminds about 10 min jog + 4×100m strides.

3. **Substitutes interval sessions with easy/fartlek runs.** Pre-PF, scheduled Wed intervals became unstructured easy runs ~3 out of 4 weeks. → Dashboard flags any Wed in a quality-prescribed week that doesn't show a structured interval HR profile.

4. **Long runs get under-distanced or skipped on busy weekends.** Sat long runs were 6 km vs 10 km prescribed (28 Mar) or skipped entirely (4 Apr). → Dashboard tracks "weekend long run completion ratio" over rolling 4 weeks.

5. **Travel weeks → near-total training stop.** Week 8 (11–17 May) had zero activities while travelling for work. → Dashboard accepts this as a "travel week" if so labeled but warns if 2 in a row.

## Pattern detection rules (for daily dashboard logic)

- **HR drift on easy runs**: avg HR – first-km HR. If consistently >15 bpm, fatigue/heat issue.
- **Pace-HR decoupling**: if same pace requires higher HR week over week, undertrained or under-recovered.
- **Volume cliff**: week-over-week total time drops >40% without scheduled rest → flag.
- **Foot stress proxy**: any run after a rest day → check if pace was respected (HR ≤155 rule).

## Cross-training equivalency

- 1 hr easy bike ≈ 30 min easy run (aerobic load)
- 1 hr MTB ≈ 45 min easy run + lower-back/forearm fatigue
- Zwift sweet spot 45 min ≈ 1 tempo run
- Weights upper/core ≠ cardio (track separately)
