# theo-training-log

Daily training dashboards for Theo. Auto-generated by the `my-training` Claude skill at 04:00 SAST every day.

- Latest dashboard: [`index.html`](index.html)
- Daily archive: `training-dashboard-YYYY-MM-DD.html`
- Source: Strava activities + active training plan

## What this tracks

- **A-race:** Imfolozi 55 km MTB — 27 Jun 2026
- **B-race:** Absa 10K Road — 10 Jul 2026
- **Season goal:** Sub-60 10K — Sept/Oct 2026

## How it updates

Cron fires `/my-training` at 04:00 SAST daily. The skill:

1. Pulls last 7 days of Strava activities via Chrome automation
2. Cross-references against the active training plan
3. Computes adherence, trends, race countdowns
4. Renders a fresh HTML dashboard
5. Commits and pushes here

If Chrome isn't running at 04:00, the cron sends a push notification and skips the update. Run `/my-training` manually after opening Chrome.

## Private repo

Activity data (pace, HR, locations) is personal. Repo is private.
