# theo-training-log

Daily training dashboards for Theo. Auto-generated by GitHub Actions at 04:07 SAST (02:07 UTC) every day.

- Latest dashboard: [`index.html`](index.html)
- Daily archive: `training-dashboard-YYYY-MM-DD.html`
- Source: Strava API + active training plan
- Cron: `.github/workflows/daily-dashboard.yml`

## What this tracks

- **A-race:** Imfolozi 55 km MTB — 27 Jun 2026
- **B-race:** Absa 10K Road — 10 Jul 2026
- **Season goal:** Sub-60 10K — Sept/Oct 2026

## How it updates

A GitHub Actions workflow runs daily at 02:07 UTC (04:07 SAST). It:

1. Refreshes the Strava access token (long-lived refresh token stored as repo secret)
2. Pulls activities from the Strava API (rolling 90-day window)
3. Merges into `data/activities.json` (dedup by date+title+duration)
4. Reads the active training plan from `plans/`
5. Renders `index.html` + `training-dashboard-YYYY-MM-DD.html` from `templates/dashboard.html`
6. Commits and pushes back to this repo

See [SETUP.md](SETUP.md) for one-time Strava OAuth + GitHub secrets setup.

## Manual runs

- **From GitHub:** Actions tab → "Daily training dashboard" → "Run workflow"
- **From your Mac:** `gh workflow run "Daily training dashboard" --repo naickert/theo-training-log`
- **Via Claude Code:** Tell Claude `/my-training` — runs the local skill (Chrome-based) as a backup if Strava API is down.

## Directory layout

```
.github/workflows/daily-dashboard.yml    # GitHub Actions cron
scripts/build_dashboard.py                # The build script
templates/dashboard.html                  # HTML template with placeholders
plans/                                    # Training plan + race-prep docs
knowledge/                                # Race calendar, injury log, journal
data/                                     # activities.json + last-sync.txt
index.html                                # Latest dashboard (= today's)
training-dashboard-YYYY-MM-DD.html        # Daily archive
```
